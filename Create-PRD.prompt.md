# Product Requirements Document (PRD)

* Create a PRD for a new product based on an Idea Refinement Document.
* The Idea Refinement Document is default `idea-xxxx.md` in the `docs` folder (where `xxxx` is the idea ID), if it does not exist then ask for a location for the Idea Refinement Document.
* The PRD should include the following sections:
  * Title with a short title of the product and "(PRD)" suffix
  * Description: A brief overview of the product and its purpose.
  * Problem Statement
  * Goals and Objectives
  * Target Audience
  * Features and Requirements
  * User Stories for all features
* The PRD should be saved in markdown format in a file `prd-xxxx.md` in the `docs` folder (where `xxxx` is the idea ID).
