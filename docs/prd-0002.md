# Simple Genealogy Application (PRD)

## Description
A desktop application for hobbyists to build, view, and manage family trees. The product provides a classic pedigree-style overview and supports rich genealogical data, including multiple photos and documents per person, with a focus on privacy and ease of use.

## Problem Statement
Hobbyists seeking to document and explore their family history often find existing genealogy tools either too complex, too limited, or requiring online data sharing. There is a need for a simple, private, desktop-based genealogy tool that supports rich data and provides a clear overview of family relationships.

## Goals and Objectives
- Enable users to easily create, edit, and visualize family trees.
- Support multiple photos and documents per person for richer family history.
- Ensure all data is stored locally for privacy.
- Provide import/export via GEDCOM for data portability.
- Offer print/export options for sharing and archiving.
- Deliver an intuitive, classic pedigree-style tree visualization.
- Support undo/redo and duplicate handling for safe editing.

## Target Audience
- Hobbyist genealogists
- Individuals and families interested in preserving their family history
- Users seeking a private, easy-to-use desktop tool

## Features and Requirements
- Create, edit, and delete individuals and relationships (parent, child, partner, sibling)
- Visual family tree overview (classic pedigree style, interactive, zoomable)
- Add/view multiple photos and documents per person
- Import/export via GEDCOM
- Print/export tree and reports (PDF, image)
- Search and filter individuals
- Local data storage (no cloud or sharing by default)
- Handle incomplete/unknown data
- Undo/redo for editing
- Support for non-traditional family structures (adoption, step-relationships)

## User Stories

- As a user, I want to create a new family tree so that I can start documenting my family history.
- As a user, I want to add, edit, or delete individuals and relationships so that my tree remains accurate.
- As a user, I want to attach multiple photos and documents to each person so that I can preserve memories and records.
- As a user, I want to view my family tree in a classic pedigree layout so that I can easily understand relationships.
- As a user, I want to import and export my tree using GEDCOM so that I can move my data between applications.
- As a user, I want to print or export my tree and reports so that I can share them with family members.
- As a user, I want to search and filter individuals so that I can quickly find specific people.
- As a user, I want all my data stored locally so that my information remains private.
- As a user, I want to undo or redo changes so that I can correct mistakes easily.
- As a user, I want to represent non-traditional family structures so that my tree reflects my real family.
