# Simple Genealogy Application – Idea Refinement

## Short Description
A desktop application for hobbyists to build, view, and manage family trees. It provides a clear, classic pedigree-style overview and supports rich genealogical data, including multiple photos and documents per person.

## Target Audience
- Hobbyist genealogists
- Individuals and families interested in preserving their family history
- Users seeking a private, easy-to-use desktop tool

## Problem Statement
Many hobbyists want to document and explore their family history without the complexity or privacy concerns of online, collaborative platforms. Existing solutions are often either too advanced, too limited, or require sharing data online. There is a need for a simple, private, desktop-based genealogy tool that supports rich data and provides a clear overview of family relationships.

## Unique Features
- Classic pedigree-style, interactive family tree visualization
- Support for multiple photos and documents per person
- Local data storage for full privacy (no cloud or sharing by default)
- Import/export via GEDCOM for data portability
- Print/export options for trees and reports
- Undo/redo and duplicate handling for safe editing

## Deferred Features
- Analytics (e.g., age statistics, family size): Deferred to keep the first version simple and focused on core needs
- Mobile/tablet support: Deferred to prioritize desktop usability and reduce initial complexity
- Collaboration/multi-user editing: Deferred to maintain privacy and simplicity
- Integration with online research databases: Deferred to avoid privacy issues and technical complexity
- Advanced visualization styles (e.g., circular, timeline): Deferred to focus on the classic view first

## Potential Challenges
- Ensuring intuitive navigation and overview for large family trees
- Handling duplicate/conflicting entries and merges
- Supporting a variety of document and image formats
- Maintaining data integrity with undo/redo and merges
- Providing a smooth, responsive user experience for all tree sizes

## Mapping Functionalities to User Needs

| Functionality                        | User Need Addressed                                 |
|--------------------------------------|-----------------------------------------------------|
| Create/edit/delete individuals       | Build and maintain accurate family records          |
| Add relationships                    | Visualize and understand family connections         |
| Visual family tree (classic style)   | Get a clear overview of family structure            |
| Add/view multiple photos/documents   | Preserve and enrich family history                  |
| Import/export via GEDCOM             | Data portability and backup                         |
| Print/export tree/reports            | Share and archive family information                |
| Search/filter individuals            | Quickly find and manage specific people             |
| Local data storage (privacy)         | Keep sensitive information private                  |
| Handle incomplete/unknown data       | Accommodate real-world genealogy challenges         |
| Undo/redo                            | Prevent accidental data loss                        |
| Support non-traditional structures   | Inclusivity for all family types                    |

## Main Interactions
- Start a new tree or import an existing one
- Add people and relationships, attach photos/documents
- Navigate and zoom the tree for overview
- Edit or delete entries as needed
- Export or print the tree for sharing

## Research Summary
- **Family Echo** ([familyecho.com](https://www.familyecho.com/)): Simple, web-based, privacy-focused, but limited in advanced features and document support.
- **RootsMagic** ([rootsmagic.com](https://www.rootsmagic.com/)): Full-featured, desktop-based, supports rich data and privacy, but more complex and paid.
- Best practices: Prioritize ease of use, clear visualizations, data portability, privacy, and support for rich genealogical data.

## Glossary
- **GEDCOM**: A standard file format for exchanging genealogical data between different software.
- **Pedigree-style tree**: A traditional family tree layout showing ancestors and descendants in a branching structure.
- **Non-traditional family structures**: Family relationships beyond biological (e.g., adoption, step-relations).
